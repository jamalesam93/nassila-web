This page lists **user-visible** planned work and known gaps. It does not cover internal training or evaluation pipelines.

## Current release

**Nassila 1.4.0 · Raqim Statute** — legislation Resolve for US federal, UK `legislation.gov.uk`, and `.gov` official catalogues; statute line-merge on import; Sharh-lite submission integrity bundle. Builds on **1.3.1 · Maktab OCR hardening**. See [Changelog](/changelog).

## Release train (planned)

App versions use **worker-themed codenames**. Suggested near-term cuts (not dated — announced when ready). Detail aligns with Nassila `docs/Nassila-Ouroboros-Future.md` §5.

| Version | Codename | Focus |
|---------|----------|--------|
| **1.5.0** | **Raqim Web** | Webpage and grey-web citations; dead links; host parsers |
| **1.6.0** | **Maktab Loop** | OCR fixtures; one-upload loop; source chunking; vision/LLM path for hard Arabic PDFs |
| **1.7.0** | **Integrity Bundle** | Preflight+; submission export; trust and packaged parity |
| **1.8.0** | **Shahid** | Tier 3+ gate; tables/figures; confirm-before-apply grey lit |

**Recommended cut order:** 1.5.0 → 1.6.0 → 1.7.0 → (NassilaT eval gate) → 1.8.0.

### Shipped — 1.4.0 Raqim Statute

- Official catalogue URLs for **US** (`congress.gov`, `govinfo.gov`, …) and **UK** (`legislation.gov.uk`)
- Generic allowlisted `.gov` / parliamentary URLs as identity
- Resolve UX copy: legal instruments vs scholarly Crossref
- Parser: statute numbers split across PDF/DOCX lines
- Sharh-lite: citation-mapping coverage + submission integrity bundle export
- Masdar: page-aware source excerpts during grounding

### 1.5.0 — Raqim Web

- HTTP status, content-type, redirect logging; dead-link visibility; paywall/archive hints
- Stable host-specific extractors (code over model)
- OpenAlex consistency when type stays `webpage`; locale-aware accessed-date
- Batch re-fetch suggestions  
Registry verify and citeproc stay **deterministic**.

### 1.6.0 — Maktab Loop

- Golden OCR fixtures; scan coverage; page provenance; cache controls
- Less module hopping: upload → segment → cited sources → grounding
- Masdar source-fetch + chunking polish
- Richer **deterministic** Sharh summaries
- A11y: loop table keyboard nav; RTL pass
- Vision/LLM Arabic OCR when ready (Tesseract Arabic remains deferred)

### 1.7.0 — Integrity Bundle

- Stronger preflight / unresolved-identity gates
- Submission integrity export (audit + bibliography + provenance)
- Projects: action log; save/reopen fidelity
- Mid-LLM abort; packaged parity; release-train CI smoke

### 1.8.0 — Shahid

- Table/figure evidence path (gated on Tier 3 holdout)
- Model-assisted grey lit: suggest CSL fields — **user confirms before apply**
- Sanad **S15** only if NassilaT go/no-go after 1.4–1.7 measurements

**Parallel (not a numbered release):** NassilaT field-note / Tier 3 curation; Sanad **S15+** when the corpus is ready.

<Callout variant="info" title="Masdar-lite is not a new AI model">
**1.2.0 Masdar-lite** (shipped) uses deterministic PDF text extraction in the app — it does **not** require downloading a new Sanad GGUF. Your existing **S12** or **S14** checkpoint stays the same.
</Callout>

## Manuscript loop (Tier 3 direction)

**Today:** Upload/paste → parse References inline → L1/L2 → OA/abstract/attach → Sanad when enabled.

**Target:** One upload; Maktab segments; Masdar ingests cited PDFs automatically; Sanad runs per cite without manual paste between modules; Shahid for tables/figures.

<Callout variant="info" title="Honest stubs">
Maktab, Masdar, and Shahid appear as pipeline gaps — not fake finished apps.
</Callout>

## Webpage and grey-web citations

Planned improvements for messy webpage references (primarily **1.5.0 Raqim Web**, with model-assisted follow-ons in **1.8.0**):

### Baseline and reliability

- HTTP status, content-type, redirect logging
- Dead-link visibility; paywall / archive hints
- Host-specific parsers where stable (prefer code over model)
- Feature flags for AI suggestions

### App refinements (no model required)

- OpenAlex consistency when `type` stays `webpage`
- Locale-aware accessed-date copy
- Batch re-fetch metadata suggestions

### Model-assisted (future)

When trained facets ship, they may help with:

| Scenario | Notes |
|----------|-------|
| Suggest CSL fields from page signals | User confirms before apply |
| Platform / grey-literature typing | YouTube, social, Substack, etc. |
| Explain fetch failures | PDF URL, Cloudflare, dead link |

<Callout variant="info" title="Registry authority">
Registry verification and citeproc formatting stay in Raqim's **deterministic** core — not LLM-replaced.
</Callout>

## Bibliography bridge (shipped)

v1.1.2 sends manuscript References to Bibliography and supports **audit from Bibliography library** with `manuscript-ref:N` cite keys. See [Bibliography bridge](/docs/bibliography-bridge).

## Long-term (not scheduled)

After **1.4–1.8** — without version numbers or dates until a later cut is decided.

| Item | Notes |
|------|-------|
| **Unified seven-worker GGUF pack** | Prefer independent checkpoints over one huge pack |
| **Full multimodal Shahid** | Beyond the gated **1.8.0** table/figure slice |
| **Embedded browser for institutional login** | Last resort after OA, attach, open DOI in browser, library proxy |
| **Default cloud LLM** | Local Sanad (S12/S14) stays the primary path |
| **Cloud collaboration / sync** | Needs project model and privacy beyond local `.nassila` files |
| **Open-ended drafting / cover letters** | Out of scope — integrity workflow, not authorship |
| **Notification center** | Not planned — light toasts only |
| **Fuzzy auto-apply on grey lit** | Near-term path: **confirm before apply** |

## What we will not promise here

- A full reference-manager replacement
- Default cloud LLM (local Sanad remains primary)
- Automatic paywall bypass via Unpaywall email
- In-app training tables, eval scores, or internal checkpoint gates
