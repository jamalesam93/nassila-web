## Manuscript loop (Tier 3 direction)

**Today:** Upload/paste → parse References → L1/L2 → OA PDF/abstract/attach → Sanad when enabled.

**Target:** One upload; Maktab segments; Masdar ingests cited PDFs; Sanad runs per cite without manual paste; Shahid for tables/figures (**2.0.0**).

<Callout variant="info" title="Honest gaps">
**Shahid** remains disabled until **2.0.0**. Maktab ingest and Masdar attach are **live**; Arabic scan OCR and table/figure evidence are not.
</Callout>

## Webpage and grey-web citations

Deterministic path shipped in **1.5.0 Raqim Web**. Model-assisted follow-ons planned for **2.0.0**:

### Baseline and reliability (shipped 1.5.0)

- HTTP status, content-type, redirect logging
- Dead-link visibility; paywall / archive hints
- Host-specific parsers where stable (prefer code over model)

### App refinements (no model required)

- OpenAlex consistency when `type` stays `webpage`
- Locale-aware accessed-date copy
- Batch re-fetch metadata suggestions
- Wayback availability gating → **1.10.0**

### Model-assisted (2.0.0+)

When trained facets ship, they may help with:

| Scenario | Notes |
|----------|-------|
| Suggest CSL fields from page signals | User confirms before apply |
| Platform / grey-literature typing | YouTube, social, Substack, etc. |
| Explain fetch failures | PDF URL, Cloudflare, dead link |

<Callout variant="info" title="Registry authority">
Registry verification and citeproc formatting stay in Raqim's **deterministic** core — not LLM-replaced.
</Callout>

v1.1.2 sends manuscript References to Bibliography and supports **audit from Bibliography library** with `manuscript-ref:N` cite keys. See [Bibliography bridge](/docs/bibliography-bridge).

## Long-term (not scheduled)

After **2.1** — without version numbers or dates until promoted.

| Item | Notes |
|------|-------|
| **Unified seven-worker GGUF pack** | Prefer independent checkpoints over one huge pack |
| **Full multimodal Shahid** | Beyond the gated **2.0.0** slice |
| **Embedded browser for institutional login** | Last resort after OA, attach, open DOI in browser, library proxy |
| **Default cloud LLM** | Local Sanad (9B) stays the primary path |

| **Open-ended drafting / cover letters** | Out of scope — integrity workflow, not authorship |
| **Notification center** | Not planned — light toasts only |
| **Fuzzy auto-apply on grey lit** | Near-term path: **confirm before apply** (2.0.0) |
| **3.0.0 Ouroboros** | Closed loop; crash recovery; signed installers |

## What we will not promise here

- A full reference-manager replacement
- Default cloud LLM (local Sanad remains primary)
- Automatic paywall bypass via Unpaywall email
- In-app training tables, eval scores, or internal checkpoint gates
- Arabic L3 grounding quality until **FT-7** ships (**2.1.0**)
