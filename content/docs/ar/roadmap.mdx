## الإصدار الحالي

**ناسيلا 1.10.1 · تماسك النسخة المعبأة** — "أبقِ عنواني" / البحث عن DOI / خطوة التحسين أونلاين / زر Resolve في شريط الإدخال تعمل الآن في النسخة المثبّتة (نُقلت استدعاءات السجلات إلى العملية الرئيسية). يبني على **1.10.0 · أوراق مصدر**. انظر [سجل التغييرات](/changelog).

## قطار الإصدارات (مخطط)

إصدارات التطبيق تحمل **أسماء مستوحاة من العمال**. مقترحات قريبة (بدون تواريخ — تُعلَن عند الجاهزية). التفاصيل توافق `docs/Nassila-Ouroboros-Future.md` §5 في مستودع التطبيق.

| الإصدار | الاسم | التركيز |
|---------|-------|---------|
| **2.0.0** | **مكتب OCR + شاهد** | OCR عربي/رؤية + أدلة جداول/أشكال (بوابة Tier 3 + متعدد الوسائط) |
| **2.1.0** | **سند عربي** | شريحة تدريب FT-7 + holdout؛ ربط عربي |

**ترتيب القطع المقترح:** 1.8.0 (شُحن) → **1.10.0 أوراق مصدر** (شُحن) → (بوابة Tier 3 + متعدد الوسائط) → 2.0.0 → 2.1.0.

> **سند FT-6** شُحن على Hugging Face (2026-08-21) — Hub/GGUF فقط؛ **بلا مثبّت 1.9.0**. استخدم التطبيق الحالي مع ملفات GGUF المحدّثة.

### 2.0.0 — مكتب OCR + شاهد

- OCR عربي/رؤية لملفات PDF الممسوحة (بديل Tesseract `ara` المؤجّل)
- مسار أدلة الجداول/الأشكال (بوابة Tier 3 + تقييم متعدد الوسائط)
- أدب رمادي بمساعدة النموذج: اقتراح حقول CSL — **يؤكد المستخدم قبل التطبيق**

### 2.1.0 — سند عربي

- تدريب FT-7 لتثبيت سند بالعربية + holdout AR مجمّد
- حتى ذلك الحين: **واجهة عربية نعم؛ تثبيت L3 بالعربية غير مُتحقّق**

## حلقة المخطوطة (اتجاه Tier 3)

**اليوم:** رفع/لصق → تحليل References → L1/L2 → PDF/ملخص/إرفاق → سند عند التفعيل.

**الهدف:** رفع واحد؛ Maktab يقسّم؛ Masdar يستوعب PDF المستشهد بها؛ سند لكل استشهاد دون لصق يدوي؛ Shahid للجداول/الأشكال (**2.0.0**).

<Callout variant="info" title="فجوات صادقة">
**Shahid** يبقى معطّلاً حتى **2.0.0**. استيراد Maktab وإرفاق Masdar **منشوران**؛ OCR عربي للمسح وأدلة الجداول/الأشكال ليسا كذلك.
</Callout>

## استشهادات صفحات الويب والويب الرمادي

المسار الحتمي شُحن في **1.5.0 رقيم ويب**. متابعة مدعومة بالنموذج مخططة لـ **2.0.0**:

### الأساس والموثوقية (شُحن 1.5.0)

- حالة HTTP، نوع المحتوى، سجل إعادة التوجيه
- ظهور الروابط الميتة؛ تلميحات paywall / archive
- محلّلات خاصة بالمضيف حيث تكون مستقرة

### تحسينات التطبيق (دون نموذج)

- اتساق OpenAlex عندما يبقى `type` = `webpage`
- نص تاريخ الوصول حسب اللغة
- إعادة جلب دفعات للاقتراحات
- بوابة توفر Wayback — شُحن في **1.10.0**

### مدعوم بالنموذج (2.0.0+)

| السيناريو | ملاحظات |
|----------|---------|
| اقتراح حقول CSL من إشارات الصفحة | يؤكد المستخدم قبل التطبيق |
| تصنيف منصات / أدب رمادي | YouTube، شبكات، Substack، إلخ |
| شرح فشل الجلب | PDF URL، Cloudflare، رابط ميت |

<Callout variant="info" title="سلطة السجل">
التحقق من السجل وciteproc يبقيان في **النواة الحتمية** لـ Raqim — لا يُستبدلان بـ LLM.
</Callout>

## جسر القائمة المرجعية (منشور)

v1.1.2 ينقل مراجع المخطوطة إلى رقيم ويدعم **التدقيق من مكتبة المراجع** مع مفاتيح `manuscript-ref:N`. انظر [جسر القائمة المرجعية](/docs/bibliography-bridge).

## طويل الأمد (غير مجدول)

بعد **2.1** — بدون أرقام إصدارات أو تواريخ حتى يُقرَّر الترقية.

| البند | ملاحظات |
|-------|---------|
| **حزمة GGUF موحّدة لسبعة عمال** | تفضيل نقاط تفتيش مستقلة على حزمة واحدة ضخمة |
| **شاهد متعدد الوسائط الكامل** | يتجاوز شريحة **2.0.0** المحدودة |
| **متصفح مدمج لتسجيل دخول مؤسسي** | الملاذ الأخير بعد OA والإرفاق وفتح DOI في المتصفح وبروكسي المكتبة |
| **LLM سحابي افتراضي** | سند المحلي (9B) يبقى المسار الأساسي |
| **تعاون / مزامنة سحابية** | يتطلب نموذج مشروع وخصوصية يتجاوز ملفات `.nassila` المحلية |
| **توليد رسائل / صياغة مفتوحة** | خارج النطاق — سير نزاهة وليس تأليفاً |
| **مركز إشعارات** | غير مخطط — إشعارات خفيفة فقط |
| **تطبيق تلقائي ضبابي على الأدب الرمادي** | المسار القريب: **تأكيد قبل التطبيق** (2.0.0) |
| **3.0.0 أوروبوروس** | حلقة مغلقة؛ استرداد من الأعطال؛ مثبّتات موقّعة |

## ما لن نعد به هنا

- بديل كامل لمدير المراجع
- LLM سحابي افتراضي (سند المحلي يبقى المسار الأساسي)
- تجاوز paywall تلقائي عبر بريد Unpaywall
- جداول تدريب أو درجات تقييم أو بوابات نقاط تفتيش داخلية
- جودة تثبيت L3 بالعربية حتى شحن **FT-7** (**2.1.0**)
