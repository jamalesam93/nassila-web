**سند** (Sanad) هو عامل توثيق الادعاءات بالمصدر في ناسيلا. يقارن الجمل في مسودتك بمقتطفات المصدر عبر خادم LLM متوافق مع OpenAI تضبطه أنت — **محلياً افتراضياً**، والسحابة اختيارية.

<Callout variant="warning" title="بمساعدة الذكاء الاصطناعي">
مخرجات سند **بمساعدة الذكاء الاصطناعي**. تُحظر الاقتباسات غير الصالحة بحواجز أمان، لكن يجب التحقق من كل حكم يدوياً قبل التسليم.
</Callout>

## تنزيل النماذج

ملفات Sanad GGUF **غير مضمّنة** في المثبّت. نزّل من Hugging Face (أحضر ملفك):

| النموذج | Model ID | VRAM (تقريبي) | Hugging Face |
|-------|----------|----------------|--------------|
| **سند 9B** (المستوى الوحيد) | `nassila-sanad-9b` | Q2_K ~3.6 GB → Q8_0 ~8.9 GB (Q6_K ~6.9 GB) | [nassila-sanad-9b](https://huggingface.co/QinEmPeRoR93/nassila-sanad-9b) |

ست كمات GGUF (Q2_K / Q3_K_M / Q4_K_M / Q5_K_M / Q6_K / Q8_0) تشترك في نفس الأوزان المدرّبة — اختر الأكبر الذي تسمح به ذاكرتك.

<Callout variant="info" title="ملاحظة: النماذج الأقدم متقاعدة">
تم **إحالة نماذج عصر الملخصات** **`nassila-sanad-4b`** (S15) و**`nassila-sanad-12b`** (S14) و**`nassila-sanad-e4b`** (S12) **للتقاعد** — يوفّر التطبيق **سند 9B** بصفته النموذج الوحيد. بطاقاتهم بقيت على Hugging Face للتنزيلات القديمة.
</Callout>

في ناسيلا: **الإعدادات → توثيق الادعاءات بالمصدر** — يعرض شريط سند رقاقة **9B** واحدة؛ يُملأ حقل النموذج تلقائياً بـ `nassila-sanad-9b` عند استخدام GGUF سند **محلي**.

<Callout variant="info" title="FT = نقطة تفتيش النص الكامل">
**FT-5** يسمّي جيل نموذج سند 9B على Hugging Face — منفصل عن إصدار التطبيق. التفاصيل: [النماذج المحلية](/docs/local-models).
</Callout>

## الإعداد في ناسيلا

<Steps>
<Step title="افتح إعدادات توثيق الادعاءات">
**الإعدادات → توثيق الادعاءات بالمصدر** (أو رابط **إعداد Sanad** داخل التطبيق — التفاصيل الكاملة هنا على الموقع).
</Step>
<Step title="اختر محلياً أو سحابة">
تح **Provider**، اختر مشغّلاً **محلياً** (LM Studio، Ollama، vLLM، Custom) لـ GGUF سند، أو **Cloud API** لنموذج طرف ثالث تجريبي.
</Step>
<Step title="اضبط عنوان URL الأساسي ومعرّف النموذج">
يجب أن يطابق عنوان URL الأساسي مشغّلك أو واجهة API. يجب أن يطابق معرّف النموذج ما يعرضه الخادم (`ollama list`، النموذج المحمّل في LM Studio، أو اسم نموذج السحابة).
</Step>
<Step title="اختبر الاتصال">
استخدم **Test connection** في الإعدادات قبل أول تدقيق. صحّح عنوان URL أو معرّف النموذج أو مفتاح API حتى ينجح.
</Step>
<Step title="فعّل في المخطوطة">
بدّل سند على **شريط سند** عند تشغيل تدقيق مخطوطة.
</Step>
</Steps>

## إعداد المشغّل والسحابة

اختر علامة التبويب التي تناسب مزوّدك. التبويبات المحلية تستخدم نموذج سند المدرّب؛ **Cloud API** يستخدم أي نموذج يوفّره البائع (الجودة غير مضمونة).

<Tabs>
<Tab label="LM Studio (recommended)">

<Steps>
<Step title="ثبّت LM Studio">
نزّل من [lmstudio.ai](https://lmstudio.ai/).
</Step>
<Step title="حمّل Sanad GGUF">
نزّل **nassila-sanad-9b** من Hugging Face (الجدول أعلاه) وحمل الملف في LM Studio.
</Step>
<Step title="شغّل Local Server">
في LM Studio، شغّل **Local Server** (واجهة API متوافقة مع OpenAI على المنفذ 1234 افتراضياً).
</Step>
<Step title="طابِق إعدادات ناسيلا">
الإعداد المسبق **LM Studio**. عنوان URL الأساسي:

<CodeBlock>http://localhost:1234</CodeBlock>

حقل النموذج: `nassila-sanad-9b` أو المعرف الدقيق الذي يظهر في LM Studio للـ GGUF المحمّل.
</Step>
</Steps>

لا حاجة لإعداد قالب — آثار تفكير Qwen3.5 تُزال تلقائياً في ناسيلا.

</Tab>
<Tab label="Ollama">

<Steps>
<Step title="ثبّت Ollama">
نزّل من [ollama.com](https://ollama.com/).
</Step>
<Step title="اسحب من Hugging Face">
<CodeBlock>ollama pull huggingface.co/QinEmPeRoR93/nassila-sanad-9b:Q6_K</CodeBlock>

اختر وسم الكم الذي تريده (Q2_K–Q8_0) وتحقق أنه يطابق اسم الملف على بطاقة النموذج.
</Step>
<Step title="طابِق إعدادات ناسيلا">
الإعداد المسبق **Ollama**. عنوان URL الأساسي:

<CodeBlock>http://localhost:11434</CodeBlock>

يجب أن يطابق حقل النموذج **`ollama list`** تماماً بعد السحب.
</Step>
<Step title="لديك .gguf على القرص؟">
أنشئ Modelfile بـ `FROM ./your-file.gguf`، ثم `ollama create` باسم تستخدمه في حقل النموذج في ناسيلا.
</Step>
</Steps>

لا حاجة لإعداد قالب — آثار تفكير Qwen3.5 تُزال تلقائياً في ناسيلا.

</Tab>
<Tab label="llama.cpp">

شغّل GGUF سند مباشرة مع `llama-server`:

<CodeBlock>llama-server -m nassila-sanad-9b-q6_k.gguf --host 127.0.0.1 --port 1234 --ctx-size 8192 --n-gpu-layers 99 --jinja --chat-template-file qwen3.5-no-thinking.jinja</CodeBlock>

نموذج Qwen3.5 **يفكّر افتراضياً**؛ بدون قالب عدم التفكير يصدر أثر `thinking` قبل JSON وينقطع الناتج. تزيل ناسيلا 1.8.0 الآثار داخل التطبيق كاحتياط، لكن استخدام القالب مع الخادم يعطي أنقى مخرجات.

أنشئ ملف `qwen3.5-no-thinking.jinja` بالقالب أدناه، ثم مرّره مع `--chat-template-file` كما أعلاه:

```jinja
{% set enable_thinking = false %}
{%- for message in messages %}
{%- if message['role'] == 'system' %}
{{- '<|im_start|>system\n' + message['content'] + '<|im_end|>\n' }}
{%- elif message['role'] == 'user' %}
{{- '<|im_start|>user\n' + message['content'] + '<|im_end|>\n' }}
{%- elif message['role'] == 'assistant' %}
{{- '<|im_start|>assistant\n' + message['content'] + '<|im_end|>\n' }}
{%- endif %}
{%- endfor %}
{%- if add_generation_prompt %}
{{- '<|im_start|>assistant\n' }}
{%- endif %}
```

<Steps>
<Step title="طابِق إعدادات ناسيلا">
الإعداد المسبق **Custom**. عنوان URL الأساسي:

<CodeBlock>http://localhost:1234</CodeBlock>

حقل النموذج: المعرف الذي يعرضه خادم `llama-server` لديك.
</Step>
</Steps>

</Tab>
<Tab label="vLLM">

<Steps>
<Step title="قدّم Sanad GGUF">
اتبع [وثائق vLLM](https://docs.vllm.ai/en/latest/) (أو خادماً متوافقاً مع OpenAI) لتقديم **nassila-sanad-9b** (مثل `nassila-sanad-9b-q6_k.gguf`) حسب GPU/RAM.
</Step>
<Step title="سجّل معرّف النموذج">
يُظهر الخادم معرّفاً في `/v1/models` — انسخه حرفياً.
</Step>
<Step title="طابِق إعدادات ناسيلا">
الإعداد المسبق **vLLM** أو **Custom**. عنوان URL الأساسي لجذر الخادم (غالباً `http://localhost:8000`). حقل النموذج = المعرف من الخادم.
</Step>
</Steps>

</Tab>
<Tab label="Custom endpoint">

لأي خادم **محلي** متوافق مع OpenAI (llama.cpp server، text-generation-webui، إلخ — مستخدمو llama.cpp يراجعون [التبويب المخصص أعلاه](#llama-cpp)):

<Steps>
<Step title="شغّل الخادم">
تأكد أن `/v1/chat/completions` متاح على عنوان URL الأساسي.
</Step>
<Step title="حمّل Sanad GGUF">
استخدم أحد تنزيلات Hugging Face أعلاه — Custom ليس بديلاً عن أوزان سند.
</Step>
<Step title="طابِق إعدادات ناسيلا">
الإعداد المسبق **Custom**. أدخل عنوان URL الأساسي ومعرّف النموذج الذي يُبلغ عنه الخادم. لـ **localhost**، أي مفتاح API placeholder غير فارغ مقبول.
</Step>
</Steps>

</Tab>
<Tab label="Cloud API">

<Callout variant="warning" title="تجريبي — ليس Nassila Sanad">
نماذج السحابة **ليست** نقاط تفتيش سند المدرّبة. جودة التثبيت **تجريبية**. فضّل GGUF **سند 9B** المحلي للعمل الحساس قبل التسليم.
</Callout>

<Steps>
<Step title="اختر مزوّد سحابة">
تقبل ناسيلا أي نقطة HTTPS متوافقة مع OpenAI. خيارات شائعة: [OpenAI](https://platform.openai.com/) أو [OpenRouter](https://openrouter.ai/) — قد يكتشف التطبيقها من عنوان URL.
</Step>
<Step title="اختر Cloud API في الإعدادات">
**الإعدادات → توثيق الادعاءات بالمصدر → المزوّد → API سحابي**.
</Step>
<Step title="الصق مفتاح API">
يُخزَّن **على هذا الجهاز فقط** ويُرسَل **فقط إلى عنوان الخادم الذي تضبطه** — لا إلى خوادم ناسيلا.
</Step>
<Step title="اضبط URL الأساسي والنموذج">
إن لم يُملأ تلقائياً، أمثلة:

<CodeBlock>https://api.openai.com/v1</CodeBlock>

<CodeBlock>https://openrouter.ai/api/v1</CodeBlock>

حقل النموذج = اسم النموذج لدى المزوّد. سند المحلي نموذج واحد **9B** — السحابة تستخدم النموذج الذي تختاره كما هو.
</Step>
<Step title="راجع الخصوصية قبل التدقيق">
يُرسَل نص المقتطف إلى **بائع السحابة** عند التثبيت. اقرأ سياسات الاحتفاظ والتدريب للمسودات الحساسة.
</Step>
</Steps>

</Tab>
</Tabs>

## الخصوصية

- **المشغّلات المحلية** — النص يذهب إلى جهازك فقط (localhost أو خادم LAN).
- **Cloud API** — النص يذهب إلى البائع الذي تضبطه.
- **ناسيلا** لا تستقبل نص المخطوطة للتثبيت؛ فحوصات L1/L2 وجلب OA إجراءات منفصلة تشغّلها أنت.

## استكشاف الأخطاء

| المشكلة | ما تجربه |
|---------|-------------|
| Connection refused | تأكد أن خادم المشغّل يعمل؛ تحقق من المنفذ |
| Model not found | طابِق معرّف النموذج مع LM Studio أو `ollama list` |
| بطء أو OOM | استخدم كم أصغر (Q2_K / Q4_K_M)؛ أغلق تطبيقات GPU |
| تثبيت فارغ | فعّل سند؛ تأكد أن المقتطف ليس `Unavailable` |
| فشل اختبار السحابة | تحقق من مفتاح API ولواحقة `/v1` واسم النموذج |
